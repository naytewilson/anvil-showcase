# Security and responsible disclosure

ANVIL's implementation is developed in a **separate private repository**. This public repository is a documentation-only technical showcase.

## Scope

This repository does **not** expose a runnable distribution, development environment, production instance, authentication endpoint, or hosted service. Its architecture diagrams are deliberately conceptual. Do not infer the private system's topology, interfaces, security controls, or operational status from the examples.

For concerns about the **public documentation or assets in this repository**, open an issue if issues are enabled, or contact [research@macbrainslabs.org](mailto:research@macbrainslabs.org).

For a **potential security vulnerability**, contact [research@macbrainslabs.org](mailto:research@macbrainslabs.org) privately with a concise description, affected public material, and reproducible observations. Do not post credentials, private data, or exploit material in a public issue.

No bug bounty, vulnerability-reward program, disclosure deadline, or support SLA is promised.

## Publication policy

Only intentionally released descriptive material belongs here. Do not submit or mirror:

- implementation source or private repository contents;
- secrets, credentials, access tokens, configuration, or network endpoints;
- real agent sessions, task/lease IDs, logs, operational receipts, or internal records;
- unpublished performance results presented as verified benchmarks.

Public documentation is not an open-source license for ANVIL's private implementation.
